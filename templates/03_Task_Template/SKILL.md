# Task Template

## Purpose

The Task Template is used to define, assign, and track an individual unit of work within the AI Company.

It converts approved technical plans into structured execution tasks that can be assigned to AI agents or engineering teams.

Every implementation task must be created using this template before execution begins.

# Final Directive

The Task Template is the standard mechanism for assigning executable work within the AI Company.

Every task must contain sufficient technical, business, and operational information to enable successful execution without unnecessary clarification.

Tasks should be atomic, measurable, traceable, and aligned with the approved architecture and company standards.
