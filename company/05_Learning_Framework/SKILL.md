# Learning Framework

## Purpose

This skill defines how the AI Company continuously learns, evolves, and improves from every experience.

The objective is to transform every project, decision, success, failure, bug, incident, customer feedback, and operational event into permanent organizational knowledge.

The company should become more intelligent after every completed project.

---

# When to Use

Use this skill whenever an agent is:

- Completing a project
- Completing a milestone
- Resolving a bug
- Fixing an incident
- Conducting a postmortem
- Reviewing project performance
- Improving workflows
- Performing Root Cause Analysis (RCA)
- Capturing best practices
- Updating Company Brain
- Improving organizational processes

---

# Do Not Use

Do not use this skill for:

- Coding implementation
- Security enforcement
- Communication rules
- Documentation formatting

Those responsibilities belong to their respective skills.

# Root Cause Analysis (RCA)

Whenever a failure occurs, perform Root Cause Analysis.

Every RCA should identify:

Problem

Symptoms

Timeline

Immediate Cause

Root Cause

Contributing Factors

Impact

Resolution

Preventive Actions

Knowledge Captured

Responsible Owner

Verification

The objective is to eliminate the underlying cause—not just the visible symptom.

---

# Success Analysis

After successful projects identify:

What worked well?

Why did it work?

Which decisions contributed?

Which practices should become standards?

Which components are reusable?

Which workflows improved productivity?

Every success should become organizational knowledge.

---

# Failure Analysis

Whenever failures occur identify:

What failed?

Why?

What assumptions were incorrect?

Could it have been detected earlier?

What standards were missing?

How can recurrence be prevented?

Failure without learning is unacceptable.

---

# Best Practice Management

Whenever repeated success is observed:

Standardize it.

Document it.

Share it.

Teach it.

Reuse it.

Integrate it into company processes.

Successful patterns should become company standards.

---

# Mistake Prevention

Whenever a mistake is identified:

Document it.

Identify warning signs.

Update standards.

Improve workflows.

Improve documentation.

Improve checklists.

Improve automation.

Update Company Brain.

The same mistake should never happen for the same reason twice.

# Learning Review Checklist

Before closing a project verify:

- Were lessons learned documented?
- Was Root Cause Analysis completed (if required)?
- Were best practices captured?
- Was Company Brain updated?
- Were reusable assets identified?
- Were standards improved?
- Were recurring risks identified?
- Were preventive actions defined?
- Will future projects benefit from this experience?

No project is truly complete until learning has been captured.

---

# Learning Anti-Patterns

Never:

- Close projects without review.
- Ignore failures.
- Ignore successful practices.
- Repeat previous mistakes.
- Hide lessons learned.
- Lose organizational knowledge.
- Perform superficial RCA.
- Treat learning as optional.

Learning is a required deliverable.
