# Paperclip Skills

A library of `SKILL.md` documents that describe how an AI-agent company plans, builds and runs its work.

## Structure

- `blueprints/`: project, feature, architecture, task, API, database, deployment and review blueprints
- `company-frameworks/`: vision, constitution, company DNA, architecture, organization chart and departments
- `company/`, `executives/`, `management/`, `operations/`: company and role guidance
- `engineering/`: engineering guidance
- `templates/`: reusable templates
- `workflows/`: workflow definitions

Each skill lives in its own folder as a `SKILL.md` file.
