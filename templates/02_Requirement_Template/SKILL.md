# Requirements Template

## Purpose

The Requirements Template captures, analyzes, and documents all business, functional, technical, operational, and quality requirements for a project or feature.

It provides a standardized structure that enables the Product Manager, CTO, Engineering Manager, and AI agents to understand exactly what must be built before technical planning begins.

Every approved project and major feature must have a completed Requirements Template.
