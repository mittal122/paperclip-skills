# Review Template

## Purpose

The Review Template is used to collect all information required to evaluate a completed project, feature, deployment, or task before formal acceptance.

It provides a standardized structure for assessing quality, validating requirements, identifying improvements, capturing organizational knowledge, and preparing the final Review Blueprint.

Every completed project, feature, deployment, or major task must be reviewed using this template.

# Final Directive

The Review Template is the official input document for evaluating completed work within the AI Company.

Every review must be evidence-based, traceable to approved requirements, and focused on improving the organization's long-term quality, knowledge, and engineering excellence.

The completed Review Template serves as the primary input for generating the official Review Blueprint and updating the Organizational Memory Framework.
