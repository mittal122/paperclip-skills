# Project Request Template

## Purpose

The Project Request Template is the official entry point for every new project within the AI Company.

It captures the founder's vision, business objectives, constraints, and expectations in a standardized format so the CEO can evaluate the request and initiate the company's project execution workflow.

Every project must begin with this template.
